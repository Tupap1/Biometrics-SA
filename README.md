# Biometrics-SA

Software for automating fish biometrics and water-quality evaluation in aquaculture (piscicultura) operations — replaces manual paper/spreadsheet tracking with a standardized digital process.

## Stack
- **Python + Flask** backend (`app.py`, `run.py`)
- **Alembic** for database migrations
- Custom frontend (`Front/`)

## Why it's interesting
A real domain-specific automation project outside of typical CRUD/SaaS work — takes a manual, paper-based agricultural process (biometric sampling, water quality checks) and turns it into a standardized, auditable digital workflow.
